# Local Password Manager

Локальный менеджер паролей с шифрованием AES-256-GCM и KDF Argon2id.

## Запуск

```bash
cp .env.example .env
# опционально задать JWT_SECRET в .env
docker compose up -d --build
```

Открыть http://localhost:8000 → задать мастер-пароль → пользоваться.

## Безопасность

- Порт опубликован только на `127.0.0.1`
- Пароли шифруются AES-256-GCM; ключ живёт только в RAM
- Потеря мастер-пароля = потеря данных (by design)
- При рестарте контейнера требуется повторный вход

## Для доступа из локальной сети

Смените порт в `docker-compose.yml` на `"0.0.0.0:8000:8000"` и **обязательно** поставьте перед контейнером reverse-proxy (Caddy/nginx) с TLS. Также в `app/api/auth.py` установите `secure=True` в cookie.
